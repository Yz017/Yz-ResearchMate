# M5 Demo Notes

Milestone M5 adds three visible changes:

- `PlanReActPlanner` on the Coordinator and Writer.
- `filter_papers` batch task.
- Stability and maintenance tooling: token-budget trimming, model fallback, backup, and eval baseline files.

Suggested demo flow:

1. Start the API service.
2. Run `rmcli task kinds`.
3. Seed a few paper records and run `rmcli task run filter-papers --query "RAG agent shortlist" ...`.
4. Run `rmcli task run weekly-report --week 2026-W17`.
5. Run `python scripts/backup.py`.
6. Run `make smoke-m5`.
7. Run `make eval`.

Artifacts are written to local OSS/cache storage and can be inspected directly from the returned keys.

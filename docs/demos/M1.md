# M1 Demo Notes

## Goal

Use `adk web` to ask questions over a local PDF knowledge base and receive answers with citations in the form `[source: paper_id, p.N]`.

## Setup

```bash
uv run python scripts/ingest.py /path/to/your-paper.pdf --paper-id paper_X --title "Paper Title"
uv run python scripts/check_m1_rag_agent.py \
  --prompt "Use the local knowledge base. What does paper_X say about its method?" \
  --expect-citation "[source: paper_X, p.1]"
uv run adk web src/
```

`scripts/ingest.py` is the only write path for adding documents to the local Chroma
knowledge base. Use `--reset` only when you intentionally want to clear and rebuild
the current local collection.

## Manual QA Prompts

1. `What does paper_X say about its method?`
2. `Summarize the main contribution of paper_X with citations.`
3. `What evidence does the local knowledge base provide about the experiment setup?`
4. `Which page supports the answer?`
5. `What does the local knowledge base say about an unrelated topic?`

Expected behavior:

- Questions 1-4 should call `search_knowledge_base` and cite returned chunks from your PDF.
- Question 5 should say the current local knowledge base does not provide enough evidence.

Local retrieval verification completed:

```text
grounded citation answers -> [source: rag_basics, p.1]
local PDF chunks -> [source: rag_basics, p.1]
advisor requirements -> [source: memory_notes, p.1]
weekly reports summarize -> [source: weekly_report, p.1]
image classification -> NONE
```

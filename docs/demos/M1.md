# M1 Demo Notes

## Goal

Use `adk web` to ask questions over a local knowledge base and receive answers with citations in the form `[source: paper_id, p.N]` or `[source: paper_id · Section]`.

## Setup

```bash
uv run python scripts/ingest.py examples/pdfs/rag_basics.pdf --reset
uv run python scripts/ingest.py examples/pdfs/memory_notes.pdf examples/pdfs/weekly_report.pdf
uv run python scripts/check_m1_rag_agent.py
uv run adk web src/
```

`scripts/ingest.py` is a local write path for adding documents to the local Chroma
knowledge base. The API/CLI ingest flow also writes through `/v1/knowledge/ingest`.
Use `--reset` only when you intentionally want to clear and rebuild the current
local collection.

## Manual QA Prompts

1. `What does paper_X say about its method?`
2. `Summarize the main contribution of paper_X with citations.`
3. `What evidence does the local knowledge base provide about the experiment setup?`
4. `Which page supports the answer?`
5. `What does the local knowledge base say about an unrelated topic?`

Expected behavior:

- Questions 1-4 should call `search_knowledge_base` and cite returned chunks from your ingested document.
- Question 5 should say the current local knowledge base does not provide enough evidence.

Local retrieval verification completed:

```text
grounded citation answers -> [source: rag_basics, p.1]
local document chunks -> [source: rag_basics, p.1]
advisor requirements -> [source: memory_notes, p.1]
weekly reports summarize -> [source: weekly_report, p.1]
image classification -> NONE
```

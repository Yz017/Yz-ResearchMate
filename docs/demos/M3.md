# M3 Demo · Memory + Knowledge API

M3 验收目标：服务运行后，`rmcli ingest` 能走本地/OSS key 入库链路并查询文档；显式写入长期记忆后，新会话能使用该偏好。

## Steps

```bash
uv run uvicorn researchmate.api:app --host 127.0.0.1 --port 8000 --workers 1
uv run rmcli health
uv run rmcli ingest examples/pdfs/rag_basics.pdf --user-id local --tag sample
uv run rmcli kb ls --user-id local
uv run rmcli chat --user-id local "RAG basics 这份资料如何要求回答引用来源？"
uv run rmcli memory add --category research_direction "我的研究方向是多模态对齐。"
uv run rmcli memory ls --user-id local
uv run rmcli chat --user-id local "请根据长期记忆说明我的研究方向。"
uv run python scripts/smoke_test.py --steps 1,2,3,4
```

## Notes

- 未配置阿里云 OSS 凭据时，`OssClient` 使用 `OSS_LOCAL_DIR` 作为本地对象存储；API 仍只接收 OSS key。
- `/v1/knowledge/ingest` 返回 job id，进度与终态由 `/v1/knowledge/jobs/{job_id}` 和 SSE events 查询。
- `DELETE /v1/sessions/{session_id}` 会在删除前归档可抽取的显式记忆；后台空闲归档默认每 5 分钟扫描一次。
